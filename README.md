# CarbonLens 🌿

A data-driven carbon footprint calculator and insights platform.

## Features
- **Dynamic Calculator**: Estimate your footprint based on lifestyle, travel, and home energy.
- **Data Insights**: See how you compare to the global average and explore interactive charts.
- **Beautiful UI**: Deep space, glowing aesthetic powered by custom CSS and animations.

## Tech Stack
- HTML5 / CSS3 / JavaScript
- Chart.js
- PapaParse (CSV processing)
- Lucide Icons & Emojis

## Getting Started
1. Serve the files over a local web server (e.g. `npx http-server`).
2. Open `index.html` in your browser.
